# Demo

在预览中直接点击下面链接，或按住 Ctrl/Cmd 点击源码中的链接：

## 标准 Markdown 链接

[打开 target.md 第 3-5 行](demo/target.md#L3-L5)

[单行锚点 #L3](demo/target.md#L3)

[同文件锚点 #L1-L2](#L1-L2)

## 裸文本锚点（无需 []() 包裹）

直接在正文里写 demo/target.md#L3-L5 也能点击跳转。

单行写法 demo/target.md#L3 同样有效。

同文件裸锚点 #L1-L2 也可以。

行内代码 `demo/target.md#L99-L100` 同样可点击。

```
代码块中的 demo/target.md#L88 也可点击。
```
